# Student Performance Analytics Dashboard

## Project Overview

This project analyzes student examination performance data using Excel and Power BI. The objective is to identify academic trends, performance patterns, and factors that influence student outcomes.

## Dataset

Student Performance in Exams dataset.

The dataset contains student performance records including demographic information, test preparation status, lunch type, and subject scores.

## Technologies Used

- Microsoft Excel
- Power BI
- Data Visualization
- Descriptive Statistics

## Skills Demonstrated

- Data Cleaning
- Data Preparation
- Data Analysis
- Dashboard Development
- Statistical Analysis
- Business Intelligence
- Data Storytelling

## Project Objectives

- Clean and prepare student performance data.
- Analyze student scores across different factors.
- Build Power BI visualizations.
- Identify trends in academic performance.
- Present insights using dashboards and reports.

## Methodology

### 1. Data Preparation
- Imported the dataset into Excel.
- Checked for missing values.
- Removed duplicate records.
- Filtered and prepared 500 rows for analysis.
- Verified data types before analysis.

### 2. Data Analysis
- Calculated descriptive statistics.
- Compared student performance across gender, lunch type, and test preparation status.
- Analyzed trends across math, reading, and writing scores.

### 3. Dashboard Development
- Built Power BI visuals to present student performance trends.
- Created charts for demographic and academic comparison.
- Used visual storytelling to communicate findings.

## Key Outcomes

- Identified patterns in student performance across different groups.
- Created clear Power BI visualizations for academic insights.
- Demonstrated the full analytics workflow from data cleaning to reporting.
